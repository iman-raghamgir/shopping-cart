# 🛍️ Shopping Cart

A modern and beautiful shopping cart application built with React, Vite, and Tailwind CSS.

![Shopping Cart](https://img.shields.io/badge/React-19.1.1-blue?style=for-the-badge&logo=react)
![Vite](https://img.shields.io/badge/Vite-7.1.7-646CFF?style=for-the-badge&logo=vitejs)
![Tailwind CSS](https://img.shields.io/badge/Tailwind_CSS-3.4.15-38B2AC?style=for-the-badge&logo=tailwind-css)

## ✨ Features

- 🛒 **Cart Management** - Add, remove, and update product quantities
- 💰 **Price Calculation** - Automatic total price calculation
- 🎨 **Modern Design** - Beautiful and responsive user interface
- ⚡ **High Performance** - Built with Vite for lightning-fast development
- 📱 **Responsive Design** - Compatible with all devices
- 🎯 **Great UX** - Smooth animations and visual effects

## 🚀 Getting Started

### Prerequisites
- Node.js (version 18 or higher)
- npm or yarn

### Installation Steps

1. **Clone the repository**
```bash
git clone https://github.com/your-username/shopping-cart.git
cd shopping-cart
```

2. **Install dependencies**
```bash
npm install
```

3. **Run the development server**
```bash
npm run dev
```

4. **Open in browser**
```
http://localhost:5173
```

## 📦 Available Scripts

```bash
# Run development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```
